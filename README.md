# 3D Fullstack Portfolio

Portfolio 3D menggunakan React + Vite + Three.js.

## Tech Stack
- React
- Vite
- Three.js
- React Three Fiber
- Framer Motion

## Install

```bash
npm install
```

## Jalankan Project

```bash
npm run dev
```

## Build Production

```bash
npm run build
```

## Deploy ke GitHub Pages

1. Upload project ke repository GitHub.
2. Pastikan branch utama bernama `main`.
3. Masuk ke:
   - Settings
   - Pages
   - Build and deployment
4. Pada Source pilih `GitHub Actions`.
5. Push project ke branch `main`.
6. GitHub Actions otomatis build dan deploy website.

File workflow sudah tersedia di:

```bash
.github/workflows/deploy.yml
```
